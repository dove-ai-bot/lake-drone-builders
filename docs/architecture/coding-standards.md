# Coding Standards

## TypeScript/JavaScript
- Use TypeScript for all new code
- Follow ESLint configuration
- Use functional components with hooks
- Prefer arrow functions for inline callbacks
- Use descriptive variable names

## React/Next.js
- Use Next.js App Router pattern
- Implement proper error boundaries
- Follow React hooks rules
- Use TypeScript interfaces for props

## CSS/Styling
- Use Tailwind CSS utility classes
- Follow mobile-first responsive design
- Implement proper accessibility (ARIA labels, semantic HTML)
- Use consistent spacing and color tokens

## File Organization
- Components in `/src/app/components/`
- Pages in `/src/app/*/page.tsx`
- Utilities in `/src/app/utilities/`
- Hooks in `/src/app/hooks/`
- Context in `/src/app/context/`

## Testing
- Write unit tests for utilities
- Test component rendering and interactions
- Follow AAA pattern (Arrange, Act, Assert)

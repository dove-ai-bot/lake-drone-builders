### Industrial Design System Context
[Source: docs/design-system/components/tailwind-structure.md#custom-utility-classes]
**Color Palette:**
- **Steel Grays**: 50-900 scale for metallic backgrounds and structural elements
- **Safety Orange**: 600-800 for primary CTAs and important actions (#ff4000, #e63900, #cc2900)
- **Industrial Yellow**: 600-700 for warnings and certification badges (#ffb400, #cc9200)
- **Technical Blue**: 600-700 for links and secondary actions (#007fff, #0066cc)

**Typography System:**
- Headers: `font-industrial` (Roboto Condensed) - uppercase, bold, wide tracking
- Technical Text: `font-technical` (Inter, Roboto) - precise, readable
- Specifications: `font-mono-tech` (JetBrains Mono) - monospace for technical readouts

**Visual Effects:**
- `shadow-rivet`: Inset shadows for rivet appearance
- `shadow-panel`: Multi-layer shadows for panel depth
- `shadow-control`: Interactive element shadows
- `metal-texture`: Subtle grid pattern overlay
- `technical-grid`: Blueprint background pattern

- **Mechanical Precision**: All animations should feel like physical machinery
- **Performance**: GPU-accelerated transforms only (scale, translate, opacity)
- **Accessibility**: Respect `prefers-reduced-motion` media query
- **Consistency**: Uniform timing and easing across all components

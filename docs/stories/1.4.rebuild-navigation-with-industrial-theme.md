### Navigation Architecture Requirements
[Source: Task research on architecture documents]
**Component Location**: `/src/app/components/`
- Current file to replace: `Navbar.tsx`
- New component: `IndustrialNavigation.tsx`

**Routing Structure**:
- Uses Next.js App Router with file-based routing
- Current routes: `/` (home), `/store`, `/about`
- New routes: `/` (home), `/products`, `/cart`, `/about`
- Use `next/link` component for navigation

**State Management for Cart**:
[Source: architecture research - ShoppingCartContext]
- Cart state managed via React Context API (`ShoppingCartContext`)
- `useShoppingCart()` hook provides:
  - `cartQuantity`: total number of items in cart
  - `openCart()`: function to open cart modal
- Cart data persisted to localStorage

### Industrial Design Specifications
[Source: docs/design-system/components/tailwind-structure.md via Story 1.3]
**Navigation Styling**:
- Styled as industrial control panel with steel texture
- Navigation items labeled as: `[INVENTORY]` `[REQUISITION CART]` `[FACILITY INFO]`
- Cart icon shows quantity badge styled as LED counter
- Mobile: Transforms to industrial drawer with riveted edges

**Color Usage**:
- Background: Gunmetal grays (steel-800/900)
- Primary CTAs: Safety orange (#ff4000, #e63900)
- Active states: Safety orange accent
- Text: Light gray on dark backgrounds
- Focus indicators: 3px amber outline with 2px offset

**Typography**:
- Navigation labels: `font-industrial` (uppercase, bold, wide tracking)
- Technical readouts: `font-mono-tech` for cart counter

**Animation Specifications**:
[Source: docs/stories/1.3.create-base-industrial-components.md#dev-notes]
- Hover effects: 200ms ease-out with subtle panel lifting
- Mobile drawer: Use `hydraulic-open` animation from Tailwind config
- Focus transitions: 200ms ease-out border illumination
- Respect `prefers-reduced-motion` settings

### Component Implementation Details
**Required Imports**:
```typescript
import { IndustrialButton } from '@/components/industrial/core/IndustrialButton';
```

**Mobile Navigation Pattern**:
- Industrial drawer pattern for mobile
- Touch targets minimum 44x44px
- Simplified animations on mobile for performance
- Escape key support for closing drawer
- Focus trap when drawer is open

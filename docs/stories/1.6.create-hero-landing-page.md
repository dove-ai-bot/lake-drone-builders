### Industrial Design Requirements
[Source: docs/design-system/theme/industrial-design-system.md]
**Color Palette**:
- Hero background: Steel gradient (steel-900 to steel-800)
- Primary CTA: Safety orange (#ff4000)
- Text: Light gray (steel-100) on dark backgrounds
- Accents: Tech blue for secondary elements

**Typography Scale**:
- Hero headline: Display text (text-4xl to text-5xl) with Roboto Condensed
- Subheadings: text-xl with Inter medium weight
- Product specs: text-mono-sm with JetBrains Mono
- CTA buttons: text-lg with semibold weight

**Spacing and Layout**:
- Hero section: Full viewport height (min-h-screen)
- Grid spacing: space-6 (24px) on desktop, space-4 (16px) on mobile
- Section padding: space-16 (64px) on desktop, space-8 (32px) on mobile
- Component spacing follows 4px grid system

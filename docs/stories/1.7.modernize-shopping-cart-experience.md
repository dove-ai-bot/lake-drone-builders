## Status

## Story

**I want** to review my selected items in a modern cart interface,
**so that** I can manage my purchases efficiently.

5. Implement modern cart storage approach with improved data structure
6. Include empty cart state with industrial messaging

**Industrial Components Available**:
- `IndustrialButton` - Use for all CTAs with mechanical animations
- `IndustrialBadge` - For status indicators and certifications
- `IndustrialCard` - Can be adapted for cart item containers
- All support industrial design tokens and hover states

### Cart Context Integration
[Source: src/app/context/ShoppingCartContext.tsx analysis]
**Available Context Methods**:
- `useShoppingCart()` - Hook providing all cart functionality
- `openCart()` / `closeCart()` - Cart visibility control
- `increaseCartQuantity(id)` - Add item or increase quantity
- `decreaseCartQuantity(id)` - Reduce quantity
- `removeFromCart(id)` - Remove item completely
- `getItemQuantity(id)` - Get current quantity for item
- `cartQuantity` - Total items in cart
- `cartItems` - Array of {id, quantity} objects

- Buttons: Safety orange (#ff4000) for primary actions

**Typography**:

- Body text: Inter for readability

### Data Structure Enhancement
[Source: Current implementation review]
**Current Structure**: `{id: number, quantity: number}[]`

**Enhanced Structure** (backward compatible):
```typescript
interface CartItem {
  id: number;
  quantity: number;
  addedAt?: string; // ISO timestamp
  selectedCertifications?: string[]; // From product certifications
  notes?: string; // For future "special instructions"
}

interface CartData {
  version: number; // For future migrations
  items: CartItem[];
  lastUpdated: string;
}
```
